# Master's Coursework

Selected reports and implementations from my master's studies in Biostatistics and Data Science. The repository focuses on completed analytical work rather than lecture material, assignment specifications, or downloaded references.

## Coursework

1. [Numerical Algorithms for Data-Intensive Science](01-numerical-algorithms-for-data-intensive-science) - numerical linear algebra, clustering, FFT, and hierarchical matrix methods in MATLAB.
2. [Deep Learning Coursework](02-deep-learning-coursework) - neural networks implemented largely from first principles in Python and NumPy.
3. [Survival Analysis](03-survival-analysis) - parametric, semiparametric, and flexible survival modelling in R.
4. [Introduction to Biostatistics](04-introduction-to-biostatistics) - epidemiological rates, clinical prediction, and causal analysis in R.
5. [Computer-Intensive Methods](05-computer-intensive-methods) - Monte Carlo, sequential inference, and Bayesian computation in MATLAB.
6. [Categorical Data Analysis](06-categorical-data-analysis) - contingency tables, log-linear models, and logistic regression in R.
7. [Theory of Statistical Inference](07-theory-of-statistical-inference) - likelihood inference, bootstrap methods, model selection, and Bayesian computation in R.

## Repository scope

- Reports are provided as PDF where a final rendered submission was available.
- Source code is included for the selected analyses and implementations.
- Course-provided datasets, assignment sheets, lecture notes, model weights, caches, and intermediate experiments are excluded.
- Some work was completed in teams. Collaborators are acknowledged in the relevant course README and original report.
- The separate Deep Learning final project is intentionally not included here.

Some analyses require datasets distributed through the original courses. Those files are omitted where redistribution rights were unclear.

## Academic integrity

These materials are published as a portfolio and historical archive. They should not be submitted as solutions to current coursework. No license is granted for reuse unless explicitly stated.
