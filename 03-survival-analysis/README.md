# Survival Analysis

Selected work from KI's Survival Analysis with Applications in Medicine course.

## Contents

- `assignment-1` - survival and hazard functions, nonparametric estimation, Cox models, time-varying effects, and model interpretation.
- `assignment-2` - extended survival-modelling exercises with a reproducible R Markdown analysis and final report.
- `presentation` - a group presentation on collapsibility and confounding bias in Cox and Aalen regression models.

The presentation was prepared with Elena Amadei, Linli Xu, Veerle Wetzels, Xintong Du, and Ziyi Wang. Course slides, solution keys, templates, and exam materials are excluded.

## Tools

R, R Markdown, `survival`, flexible parametric models, Cox regression, and medical event-time analysis.
