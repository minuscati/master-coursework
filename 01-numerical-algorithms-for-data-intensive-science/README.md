# Numerical Algorithms for Data-Intensive Science

## Contents

- `homework-1` - Gram-Schmidt variants, greedy column selection, randomized SVD, and image/video approximation experiments.
- `homework-2` - k-means, graph construction, similarity measures, spectral clustering, and image-data experiments.
- `homework-3` - recursive FFT, matrix bisection, and fast matrix-vector multiplication for hierarchical low-rank structure.

Each homework contains a final report and its supporting code. Large generated image sequences, videos, duplicate drafts, and course-provided data are omitted.

## Tools

MATLAB, numerical linear algebra, clustering, spectral methods, FFT, and hierarchical matrices.
