# Theory of Statistical Inference

Three computer assignments from Stockholm University's Theory of Statistical Inference course, completed with Ziyi Wang.

## Contents

- `assignment-1` - maximum-likelihood estimation, Newton-Raphson optimization, Fisher information, standard errors, and parametric bootstrap.
- `assignment-2` - Wald, likelihood-ratio, and score tests together with confidence intervals and profile likelihood.
- `assignment-3` - AIC, leave-one-out cross-validation, Bayesian logistic regression, Metropolis-Hastings sampling, and posterior prediction.

Each folder contains a final report and the associated R Markdown source. Data downloaded by the analyses and course materials are not duplicated here.

## Tools

R, R Markdown, likelihood inference, numerical optimization, bootstrap, hypothesis testing, cross-validation, and MCMC.
