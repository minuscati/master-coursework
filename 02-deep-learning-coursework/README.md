# Deep Learning Coursework

Four individual assignments from KTH's Deep Learning course, covering neural-network components implemented largely from first principles with Python and NumPy.

## Contents

- `assignment-1` - linear image classification, softmax and multi-label binary cross-entropy objectives, gradient checks, and mini-batch training.
- `assignment-2` - a two-layer network, cyclical learning rates, regularization search, and optimization extensions.
- `assignment-3` - convolutional image classification, patch extraction, label smoothing, augmentation, and model-capacity experiments.
- `assignment-4` - a character-level recurrent neural network, backpropagation through time, text synthesis, and training variants.

Final reports and selected final implementations are included. CIFAR-10, text corpora, trained weights, generated outputs, and intermediate experiment versions are omitted.

The course final project is intentionally excluded because it will be presented in a separate repository, where starter code and personal contributions can be documented clearly.

## Tools

Python, NumPy, PyTorch for gradient verification, neural networks, CNNs, and RNNs.
